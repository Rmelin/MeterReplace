Forbedringsplan

Prioriteret plan for næste forbedringer i MeterReplace med fokus på drift, overblik og hurtigere reaktion i marken.

Opdateret 05/07/2026 Fokus: admin, VVS og mobil Anbefalet start: notifikationer

Prioriterede forbedringer

  1. 1

    Mobil-notifikationer til VVS og admin

    Send relevante beskeder ved ny opgave, ændret tidspunkt, beboersvar, behov for ny dato og manglende foto. Start simpelt med e-mail/SMS eller PWA-push afhængigt af hvad brugerne allerede har adgang til.

    Høj effekt Mindre spildtid Mobil først
  2. 2

    Dagsafslutning for admin

    Lav en samlet afslutningsvisning pr. arbejdsdag med manglende fotos, ikke hjemme, fejl ved måler, uløste noter og opgaver der mangler endelig status. Admin skal kunne se om dagen kan lukkes uden at gennemgå alle opgaver manuelt.

    Admin Kvalitetssikring Dagslukning
  3. 3

    Planlægningsassistent med kapacitet og rutehensyn

    Udbyg planlægningen med forslag baseret på VVS-tilgængelighed, geografisk nærhed, målerbrønde, blokeringer og historik for ikke hjemme. Målet er bedre dagsplaner med færre manuelle justeringer.

    Planlægning Kapacitet Ruter
  4. 4

    Audit-log på kritiske ændringer

    Registrer hvem der ændrer status, tidspunkt, koordinat, note og fotos. Det gør fejlsøgning konkret og reducerer usikkerhed når flere arbejder samtidig.

    Drift Sporbarhed Support
  5. 5

    Import-validering med fejlrapport

    Gør registerimport mere robust med forhåndsvisning af fejl, dubletter og manglende felter før data gemmes. Det reducerer manuel oprydning senere i flowet.

    Datakvalitet Import Forebyggelse

Anbefaling

Start med notifikationer, men lav dem regelstyrede fra starten. En dårlig notifikationsfunktion larmer. En god funktion sender kun beskeder, når brugeren kan handle på dem.


Første version bør have: hændelsestype, modtagerrolle, kanal, sendetidspunkt og log over afsendelser. Det er nok til drift uden at gøre løsningen tung.

Notifikationer på mobil

Trigger Modtager Besked Kanal Prioritet
Ny eller ændret opgave VVS Adresse, tidspunkt og link til opgaven. PWA-push eller SMS Høj
Beboer beder om ny tid Admin Adresse, nuværende tid og direkte link til planlægning. E-mail + dashboard Høj

Faser

  • Fase 1: Besked-logik Definer hændelser, modtagere og skabeloner. Ingen ekstern kanal er nødvendig endnu.
  • Fase 2: Første kanal Implementer den billigste stabile kanal først: e-mail, SMS eller PWA-push afhængigt af driftsbehov.
  • Fase 3: Brugerindstillinger Lad admin og VVS vælge hvilke beskeder de vil have, og hvornår de må sendes.
  • Fase 4: Måling Vis om notifikationer bliver sendt, fejler eller fører til handling.

Tekniske beslutninger

Beslutning Anbefaling Begrundelse
Kanal i første version Start med e-mail eller SMS hvis PWA ikke allerede bruges aktivt. Lavere risiko og hurtigere driftseffekt. PWA-push kræver tilladelser, service worker og browserafhængigheder.
Notifikationsdata Gem alle afsendelser i en tabel. Det gør support og fejlsøgning muligt, især ved manglende beskeder.
Støjkontrol Indfør deduplikering og cooldown pr. opgave. Brugere ignorerer systemet, hvis samme opgave sender for mange beskeder.
Sikkerhed Links skal kræve login og rollecheck. Notifikationer må ikke fungere som adgang udenom eksisterende rettigheder.
